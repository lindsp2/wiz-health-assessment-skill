# No third-party Python dependencies.
#
# This tool runs on the Python 3.8+ standard library only (urllib, json, csv,
# zipfile, xml.etree, etc.). There is nothing to `pip install` to run a health
# assessment — clone, set your Wiz credentials in .env, and go.
#
# The optional PDF deck is rendered by LibreOffice, a SYSTEM package (not pip),
# provisioned by ./install.sh when you choose the PDF option. Google Slides is
# not used or required (the advanced --format slides path also uses only stdlib).
